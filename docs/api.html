STATIC API GUIDE · v0.1

Trust the grid before the picture.

A compact reference for the public Python interface used to diagnose sampled optical propagation experiments. This file works offline and needs no documentation server.

Quick start

from propagation_sanity import (
    GridSpec, PropagationSpec, sanity_check
)

report = sanity_check(
    U0,
    grid=GridSpec(dx=2e-6, min_feature_size=100e-6),
    propagation=PropagationSpec(wavelength=532e-9, z=10e-3),
)

print(report.to_text())
report.save_json("report.json")
Units: all lengths, sample pitches, wavelengths, and propagation distances use metres. The input field is a two-dimensional NumPy array and is converted to complex128.

Main API

sanity_check

sanity_check(U0, *, grid, propagation, model=ASM_MODEL, thresholds=None, reference_model=None) → SanityReport

Runs all six evidence groups once. The selected model fully owns propagation details such as band limiting and internal padding. A separate reference_model adds a scale-invariant, physical-coordinate comparison under Model validity.

check_by_name

check_by_name(report, name) → CheckResult

Returns a named check, useful for assertions and experiment summaries.

render_status_matrix

render_status_matrix(reports, *, output_path=None, title=None, figsize=(7.2, 5.5), show=False)

Renders checks as rows and labeled configurations as columns. Pass one report, a dictionary, or a sequence of (label, report) pairs. The default is non-interactive, so examples and tests do not block.

Custom propagators

The minimum extension point is one callable. Without analytic hooks, four checks still run and the other two report SKIP rather than inventing evidence.

from propagation_sanity import PropagationModel, PropagationResult

def propagate(field, grid, propagation):
    output, x, y = your_solver(field, grid, propagation)
    return PropagationResult(output, x, y)

MY_MODEL = PropagationModel("My solver", propagate)

To enable transfer-function sampling, supply transfer_phase(FX, FY, propagation) returning an unwrapped analytic phase array. To enable an analytic model check, supply validity_hook(field, grid, propagation, active_mask, FX, FY) returning metrics and preferably phase_error_rad plus a human-readable criterion.

Report semantics

StatusMeaning
INFODescriptive evidence; does not affect the verdict.
PASSNo configured criterion fired.
SKIPThe model supplied insufficient evidence for that check. Overall becomes WARN.
WARNMarginal sampling, window, approximation, or comparison evidence.
FAILAt least one failure threshold fired; overall becomes FAIL.

The six checks

Grid summary records dimensions, physical extents, frequency increments, Nyquist limits, and output sampling. Input sampling measures spectral-edge energy, adjacent phase steps, and optional samples per known feature. Window / FOV compares energy near input and output boundaries. Frequency sampling estimates the narrowest half-power feature on a denser FFT grid. Propagator sampling tests analytic transfer-phase increments over the active spectrum. Model validity combines an optional analytic approximation criterion with an optional reference propagation.

Utilities

centered_axes, frequency_grid, fft2c, and ifft2c expose the package’s coordinate convention. gaussian_field and square_aperture make compact, deterministic test fields. field_errors returns peak-normalized intensity NRMSE and globally phase-aligned complex NRMSE.
